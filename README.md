# Protuoliuko paklausos radaras V19

V19 sutvarko V18 pastebėtas logikos ir sąsajos problemas.

- Progų kalendoriuje yra visas iš vartotojos pateiktų lapų perkeltas edukacinių progų rinkinys ir papildomos pagrindinės progos; kintamos datos skaičiuojamos pagal metus, abejotinos pažymėtos kaip preliminarios.
- Progų lange aiškiai rodoma, kiek progų yra visame kalendoriuje ir kiek patenka į pasirinktą horizontą.
- Mokymo temoms ilgi kelių mėnesių intervalai pakeisti trumpesniais tikėtinais pagrindiniais pikais. Publikavimo laikas ir mokymo pikas atskirti.
- Trupmenų, daugybos, dalybos, skaičių tiesės, matavimo ir kitų vadovėlių sekos temų langai sutrumpinti.
- Pašalintas kūrėjui skirtas produkto JSON / vieno URL diagnostikos ekranas.
- Produkto numerio parseris pirmiausia ima Pxxx iš produkto pavadinimo, todėl P213 nebeturėtų virsti atsitiktiniu puslapio skaičiumi.
- Planavimo datos valdiklis perkeltas į šoninę juostą, todėl virš PROTUOLIUKAS antraštės nebelieka nukirsto elemento.
- Esamų produktų foninis atnaujinimas išlaikytas.

Balai ir datos yra planavimo heuristika, ne tariami GA4/GSC duomenys.
